Optional 3D models for the player pieces.

Drop a file named after the piece here, as .glb (preferred) or .stl:
  car, hat, dog, boot, ship, iron, cannon, wheelbarrow
e.g. public/pieces/hat.glb

Each model is scaled to piece size, stood on the board and given the silver metal finish.
Pieces without a file keep the built-in silhouette. Rebuild (npm run build) to include new files in the .exe.
Check the model's licence allows use in this game.
